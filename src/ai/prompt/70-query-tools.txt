QUERY TOOLS: MCP tools for your PAST — what you built, said, and did. For anything about the world AROUND you right now (terrain, what is under you, where a material is), use [CTX:...] above instead; there is no tool for those.
- query_structures: list all structures you've built (names, locations, block counts). Use before navigating to or resuming a build.
- query_structure_detail(structure_id): get full details about a specific structure — blueprint, placed blocks, missing blocks, completion %. Use when resuming construction or checking build status.
- list_biomes: list all biomes explored so far, with section counts and coordinate ranges.
- locate_biome(biome_name, current_chunk_x, current_chunk_z): find nearest explored chunks of a specific biome. Chunk coords = floor(blockX/16). Returns block-level center coordinates for goto.
- inspect_container(x, y, z): query contents of a specific container (chest, barrel, furnace) at coords. Shows items with counts from last time the bot opened it.
- query_chat_log(limit?, username?, minutes_ago?): get recent chat history — player messages, bot replies, game events (joins, deaths, advancements). Use to recall conversations or check who was online.
- search_chat_log(query): search all chat history by keyword. Find when something was discussed, who died, what was crafted, etc.
- search_events(target_pattern, type?): search game events by item/block/entity name across ALL types (mine, place, kill, craft, smelt, pickup, drop, give, deposit, withdraw, death). E.g. search "diamond" shows all diamond activity.
- recent_events(type?, limit?): latest game events. Filter by type to see recent mines, kills, crafts, etc.
- event_stats(type?): aggregated totals — blocks mined by type, mobs killed, items crafted, etc.
- events_near(x, y, z, radius?, type?): find events near coordinates — what was mined/placed/killed in an area.
- read_records(ids): full text of journal records, e.g. "r23-r25,r34" — when a note's basis matters and its record is no longer in view.
- query_task_history(limit?, search?): history of agenda/plan edits — every [PLAN:] op, who issued it, when, and the agenda after it. Older rows are legacy task-stack changes.
Every turn starts from a blank conversation BY DESIGN: the context (AGENDA, NOTES, NEW=, inv=, VISION=…) IS your memory. Do NOT use these tools to catch up on what happened — see CATCHING UP under MEMORY. Call one for a SPECIFIC question the context cannot answer ("what's in the chest at X?", "where did I build the house?"), and if the answer will matter again, note it.
